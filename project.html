Project Overview

Summary of the mental health awareness project

This project focuses on raising awareness about mental health.

It includes educational content, resources, and interactive elements.

Users can explore information, watch videos, and view helpful tips.

The goal is to promote emotional well-being and reduce stigma.

This project demonstrates web development skills using HTML and CSS.
